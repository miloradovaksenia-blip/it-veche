# Чек-лист ручной проверки на смартфоне (5 минут)

Проверяйте на **демо-сессии** с публичным HTTPS-адресом, на iPhone (Safari) и Android (Chrome).

- [ ] QR с экрана зала открывается камерой телефона и ведёт на страницу голосования (HTTPS, без предупреждений).
- [ ] До начала тура видно «Голосование скоро начнётся». После «Начать голосование» страница переключается сама, без обновления.
- [ ] Карточки читаются в вертикальной ориентации, текст не обрезан, касание по всей карточке выбирает вариант.
- [ ] «Отдать голос» → «Вы выбираете …» → «Подтвердить» → «Ваш голос принят!».
- [ ] Повторное открытие ссылки показывает «Вы уже проголосовали».
- [ ] Авиарежим, затем попытка проголосовать: видно «Голос НЕ отправлен», ложного «Голос принят» нет. После включения сети «Отправить ещё раз» срабатывает.
- [ ] Счётчик на экране зала растёт по мере голосования, распределение не видно ни на телефоне, ни на экране.
- [ ] После «Показать результаты» на телефоне появляются итоги. Во втором туре видны только два варианта.
- [ ] Итог «Цифровая эстафета»: кнопка «У меня есть кейс!» открывает форму, заявка отправляется.
- [ ] Экран зала на проекторе: 16:9, без полос прокрутки, текст читается с дальнего ряда.
- [ ] Системная настройка «Уменьшить движение» включена: анимации заметно спокойнее.
- [ ] После проверки нажмите «Сбросить демо» или «Удалить демо».

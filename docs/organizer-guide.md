# Памятка организатору ИТ-вече

**Создать сессию → вывести QR → открыть тур → закрыть → показать результаты → при необходимости второй тур → зафиксировать итог.** Всё занимает 5–7 минут.

| # | Шаг | Где | Что происходит |
|---|---|---|---|
| 1 | Создать сессию | `/admin` → «Новая сессия» | Укажите ожидаемое число участников и вопрос повестки. Решите, показывать ли «Голоса в реальном времени» (включено по умолчанию, можно переключить в любой момент в блоке «Повестка вече»). Для строгого режима отметьте «Вход по одноразовым кодам» и распечатайте карточки. |
| 2 | Показать повестку | «Экран зала (16:9)» → «Во весь экран» | На проекторе и на телефонах — повестка: вопрос, три варианта с описаниями, QR-код. Дайте участникам время ознакомиться. |
| 3 | Открыть тур | «Начать голосование» | Телефоны сами переключаются на голосование. На экране счётчик «Голосов принято: XX из YY». Если включены «Голоса в реальном времени», распределение видно на экране, у вас и у уже проголосовавших; иначе оно скрыто до показа результатов. |
| 4 | Закрыть тур | «Завершить голосование» + подтверждение | Голоса больше не принимаются. Предварительный итог видите только вы. |
| 5 | Показать результаты | «Показать результаты» | На экране «ИТ-вече завершено», пауза, раскрытие диаграмм и вывод по правилам. |
| 6 | Второй тур (если нужен) | «Запустить второй тур» или «Запустить тай-брейк» | Нужен, если ни у кого нет больше 50%. Тай-брейк — если равенство мешает определить двух финалистов. Затем повторите шаги 4–5. |
| 7 | Ничья во втором туре | «Переголосовать» или «ГД выбрал …» | Победитель не назначается автоматически. |
| 8 | Зафиксировать итог | «Зафиксировать решение» + подтверждение ГД | На экране «РЕШЕНИЕ ПРИНЯТО». Для «Цифровой эстафеты» участники видят кнопку «У меня есть кейс!». |
| 9 | После встречи | «Экспортировать CSV» | Итоги по турам без ключей участников и контактов. Заявки добровольцев смотрите в отдельном блоке панели, по запросу их можно удалить. Ненужную сессию целиком удаляет кнопка «Удалить вече» (необратимо, сначала выгрузите CSV). |

**За 10 минут до встречи:** прогоните демо («Демо» → «Начать голосование» → кнопка-пресет → завершить → показать → сбросить) и отсканируйте QR с двух телефонов через Wi-Fi зала и через мобильную сеть.
